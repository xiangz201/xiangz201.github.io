# Xiang Zhang — Academic Homepage

A static, responsive personal website. Open `index.html` locally to preview. No dependencies or build step.

## Deploy
Create a public repository named `xiangz201.github.io`. Upload the contents of this directory (not the enclosing directory). In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, and Save. Visit https://xiangz201.github.io/ after deployment.

## Edit
Edit `index.html` for text and publications, `style.css` for layout, and `assets/` for images. Duplicate a publication article to add a paper. Keep filenames and links consistent. Do not upload private materials.
